# R272：有效页重定向链超过 16 跳时读取失败

状态：修复 `PgPage::get()` 的固定跳数限制；仅关闭这一原生页 API 缺陷，不代表 SQL/HOT 全部语义、STO-03 或原 273 项总清单完成。

## 缺陷及修改方法

| 问题 | 影响 | 修改方法 |
| --- | --- | --- |
| 页面 API 可以依次建立超过 16 跳的有效重定向链，但 `get()` 最多跟随 16 跳 | 页身份、校验和及结构均有效，读取较早槽仍返回 false；`PageWrapper::read()` 同样受影响，压缩不消除该限制 | 遍历上限改为页面实际槽数；每次访问检查槽状态及下一个目标范围，找到正常行后返回完整数据，否则失败 |

只修改 `src/storage/PgPage.cpp` 的读取遍历。无需新增集合或分配；有 N 个槽的无环链最多访问 N 个槽即可读到终点。
继续设置有限上限，不采用无限循环；失败不修改返回指针或长度。未修改头文件、签名、布局、磁盘格式或重定向写入规则。
这是真实页 API 复现，不声称已经取得某条 SQL 生成长链的复现，也不声称修复所有 HOT 或损坏页检查。
