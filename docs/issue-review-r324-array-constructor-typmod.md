# R324：ARRAY 结果描述符丢失元素 typmod

状态：静态 ARRAY 修饰符传播及其普通协议输出已修正并完成下列有限验证；完整协议仍有独立未修复差异，不代表全部数组/总清单完成。

## 影响、原因和修改方法

`SELECT ARRAY[CAST('abc' AS character(4))] AS v` 的真实数据已由 R323
修正，但结果描述符仍返回 typmod -1，PG18.6 为 8（长度 4 加 4）。
同类缺口影响字符、位串、NUMERIC、时间/INTERVAL 以及嵌套数组的客户端
描述信息。不能从数组里的实际字符串长度猜测声明。

绑定器 ArrayExpr 分支生成数组类型但未记录元素共同 modifier，随后
declaredType 的无长度结果覆盖为 -1。应只在此分支复用已有 commonModifier：
标量元素对照实际元素类型，嵌套元素对照数组类型；所有子项类型及 modifier
相同才保留，否则 -1。在声明类型生成后记录节点 modifier，不执行值。
不改变通用 CAST/CASE、窗口、参数值、数组数据和物理 OID 规则。
