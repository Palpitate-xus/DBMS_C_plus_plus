## 已确认的问题与候选方法

旧已接受源码把函数体与属性按行存储、逐行读取。真实 LF/CRLF、行注释及
尾随换行可能使函数体截断、语言/返回类型等属性错位，关闭重开后仍可能出错。
候选方法是完整字段的长度编码、记录校验及从完整字节读取旧记录；保留旧文件
读取，不自动改写，不承诺旧二进制能读取新格式。旧记录没有校验，不能据此
恢复已经丢失的字节或识别任意损坏。此方法尚未纳入已接受版本。

本项不恢复用户暂缓的 R222 函数重载身份，不接受工作区的 RoutineStore、
Main 或其他外来草稿，也没有用 Root 集成投影代替纯提交源码的验证。
