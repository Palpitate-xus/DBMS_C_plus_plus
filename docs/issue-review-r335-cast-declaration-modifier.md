# R335：物理类型 CAST 的协议长度默认值错误

状态：协议声明modifier错误已修复并完成下述有限验证；独立未修复问题和用户暂缓项保留。

SQL关键词 CHAR/CHARACTER、BIT 未指定长度时默认1；物理类型名
bpchar、pg_catalog.bpchar、pg_catalog.bit（含引号）未指定长度则无约束。
旧协议描述适配器按删去schema后的字符串套用关键词默认值，并用-1同时
表示“非CAST”和“明确无约束”，污染NULL/空结果/参数等描述。

修复方法：解析真实CAST声明、按当前目录解析实际OID，并区分语法关键词
与物理类型身份。用optional保留“无CAST声明”与“真实typmod=-1”的区别。
显式长度和时间/INTERVAL既有分支不改变，不根据行数据推断声明，不执行参数。

原304请求及完整期望为777矩阵的精确前缀；原有未修复项保留原失败，不可称
全套通过。新增请求还发现BIT数组CAST错误42846，属于独立转换/共同类型问题，
不由本次协议描述修复。R334数组写入已按用户最新要求暂缓，测试草稿保留、
未应用生产修改、不得计作完成。本次不得恢复任何先前跳过模块。
