# R274：自重定向把正常页槽变成不可读循环

状态：修复原生页重定向写入的自引用准入错误；不代表 SQL/HOT、所有页操作或原 273 项总清单完成。

## 缺陷与修改方法

| 缺陷 | 影响 | 修改方法 |
| --- | --- | --- |
| `PgPage::redirect(from,to)` 允许两个编号相同，只检查两者均为正常槽 | 同一正常槽被改为长度 0、指向自身的重定向，返回成功且写入有效校验和；原行及指向它的别名读不到值，后续压缩不恢复该行 | 在写入任何页面字节前拒绝 `from == to`，保持整个页面及所有原行不变 |

`PageWrapper::redirect()` 也经同一入口修复，包括外部编号 0 对应内部编号 1 的情况。
生产仅添加入口相等性检查及说明注释。不同正常槽之间的重定向、其他状态/范围拒绝、头文件、布局、签名、校验和算法及磁盘格式不改。
原来的正常目标检查继续保留，不允许目标已经是重定向；本项防止该写入入口新制造自循环，不负责修复已经损坏的历史页面或其他操作造成的悬空引用。
这是通过实际页 API 复现的缺陷；未取得某条现有 SQL 直接生成自重定向的复现，不将其描述为已确认的 SQL 数据丢失路径。
