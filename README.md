# DBMS C++

用 C++ 编写的开源关系型数据库。可以用 SQL 建表、查数据，也可以用 `psql` 连接。

[编译和启动](docs/MANUAL.md#1-快速开始) · [用 psql 连接](docs/MANUAL.md#18-网络服务)

## 最近更新

<details>
<summary>可以在表里保存对象编号 · 2026-11-24</summary>

例如，迁移记录可以保存原表的编号，最大可到 4,294,967,295。没有编号的记录可以留空，和编号 0 区分开。

</details>

<details>
<summary>两张表按编号匹配时，取第一条更快 · 2026-11-23</summary>

在一组测试中，先把两张表的编号转成同一种类型，再查找相同的编号。取第一条结果的时间从约 310 毫秒降到了约 6 毫秒。

</details>

<details>
<summary>查一张子表的父表名称更快 · 2026-11-23</summary>

在包含 128 条表继承关系的一组测试中，这项查询的时间从约 170 毫秒降到了约 15 毫秒。

</details>
