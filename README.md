# DBMS C++

用 C++ 编写的数据库，支持用 SQL 建表、查询、添加、更新和删除数据。

[安装与快速开始](docs/MANUAL.md#1-快速开始) · [文档目录](docs/README.md)

## 最近更新

<details>
<summary>大表清理后，插入和更新更快了</summary>

例如给一张很大的订单表添一笔，数据库可以直接复用清理出的空页，省去逐页寻找写入位置的时间。更新也可以这样复用空间。

</details>

<details>
<summary>清理表后，重启也能读到新写入的数据</summary>

插入或更新复用 `VACUUM` 腾出的空间时，数据库会先把这块空间从空闲清单里取出，避免新数据写进去后，重启却打不开这张表。

</details>

<details>
<summary>一笔事务里连续修改订单更快了</summary>

例如，先改一笔订单，再按编号批量更新或删除时，即使要扫描整张表，数据库也能先检查编号，只对符合范围的订单检查其余条件。

</details>
