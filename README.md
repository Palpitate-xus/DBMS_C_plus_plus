# DBMS C++

用 C++ 写的关系型数据库。支持 SQL 读写、索引和事务，可以用 `psql` 连接。

[快速开始](docs/MANUAL.md#1-快速开始) · [连接数据库](docs/MANUAL.md#18-网络服务) · [文档目录](docs/README.md)

## 最近更新

<details>
<summary>查询不选列时，也会逐行返回结果 · 2026-11-23</summary>

例如，只查某家店的订单行。如果有 3 笔符合条件的订单，客户端就会收到 3 行，每行没有字段值。

</details>

<details>
<summary>有些查询只取几条结果时，读够就可以停下 · 2026-11-23</summary>

例如，从一批订单中取 5 笔并计算金额。在支持的查询中，数据库可以只读需要的订单。

</details>

<details>
<summary>部分查询会先返回结果，再报告错误 · 2026-11-23</summary>

例如，前两条记录算出了结果，第三条遇到除以零。客户端会先收到前两条结果，再收到错误消息。

</details>
